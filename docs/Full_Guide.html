Look. Browse. Arrange.

A practical guide to gazegallery’s viewer, folders, media tools and collage canvas.

Getting started

Extract the whole portable ZIP into a writable folder on Windows x64. Run gazegallery.exe; keep runtime, plugins and Support together. No separate .NET installation is needed. Open File, drag a file onto the top half of the window, or use Folder Tree to choose a folder. Opening a file through Explorer overrides the startup folder. Settings can start on the Startup Page or in a chosen folder, in view or thumbnail mode. Windows File Associations registers supported extensions and opens Windows default-app settings for confirmation.

Formats and performance

Supported files: JPG/JPEG, PNG, BMP, GIF, WebP, SVG, HEIC/HEIF, AVIF, JP2, TIFF/TIF, ICO, MP4 and WebM. GIF and animated WebP play as animations. Extended image formats are rasterized for viewing; multi-page files generally display the first image. Video playback uses mpv. Thumbnail and film-strip caches load ahead; loader concurrency and preview quality are configurable. Large folders show a skeleton while loading. Diagnostics provides local performance graphs. Huge videos use a buffering placeholder instead of retaining two large players.

Viewing and navigation

Next: F, D, Right Arrow or mouse forward. Previous: A, S, Left Arrow or mouse back. J toggles a new random shuffle while keeping the current image at the start. EOF behaviour can loop or navigate sibling folders. X/Tab opens Folder Tree; Z switches thumbnails/viewing. Enter toggles fullscreen. Double-click first refits a manually zoomed image, then toggles fullscreen when already fitted. H flips horizontally, N vertically, R rotates clockwise, and I toggles a persistent greyscale view filter. These viewing transforms do not edit the file. P switches image sampling.

Zoom, backgrounds and windows

Wheel zooms still images; zoom-in follows the pointer and zoom-out gradually recentres. Once manually zoomed, dragging pans instead of starting a file drag. Fit presets: window, width, height, comfy fit and original size. Right-click Zoom to choose a saved fit preset or background: Solid Color, Auto edge colour, Blur or Checkerboard. Auto and Blur apply to still images. Window Behaviour offers Windowed and Borderless; right-click Borderless chooses whether the window fits the image or the image fits the window. In image-sized borderless, left-drag moves the window until manually zoomed; Ctrl/Shift-drag always moves it, and Ctrl/Shift-wheel resizes it. A fullscreen exit control appears near the top when enabled.

Thumbnail layouts and selection

Grid uses 4:3 cells; Masonry is the fresh default; River scrolls horizontally. Click the layout button to cycle. Zoom In/Out or Ctrl-wheel changes columns/rows from two to nine. Names can be shown on two lines with ellipsis. Ctrl-click toggles selection, Shift-click selects a range, and an ordinary click selects only that item. Ctrl+A toggles all images. Drag selected files together to another viewer, collage or folder. Subfolders support selection and drops; image and folder selections cannot be mixed. Go Up cannot be selected. Removed images leave placeholders until a layout/sort/folder/view change; undo restores their spots.

Browsing, filters and previews

Folder Tree includes recent folders, pins and a resizable tree. Use arrows to expand, names to navigate; the same folder does not reload. Plus pins the current folder and minus removes a pin. Filter matches any filename text; a query starting with a period matches filename endings/extensions. Changing the filter returns to the top and stops autoscroll. Hold Alt over a thumbnail for a large preview; animations and videos play. The whole client area dims and a skeleton appears while loading. W opens a single selected image. Returning to thumbnails aligns and flashes the viewed image; mouse back returns immediately after entering view from thumbnails until you navigate to another image.

Autoscroll and folder boundaries

Space toggles thumbnail autoscroll. Choose 30, 60, 120 or 240 pixels/second, or edit the speed and press Set. Opening the speed menu pauses scrolling and resumes afterward. Selecting, dragging, using quick sort or scrolling the wheel does not stop it. Up/Down arrows scroll smoothly. At a boundary, scroll again in the same direction after the hint to loop or visit a sibling. Autoscroll counts down three seconds before continuing; sibling traversal includes empty folders. To Top jumps up and its right-click menu offers To Bottom. Fade Away hides the toolbar when the pointer leaves its area.

Moving, copying and quick sort

Q opens/closes Quick Sort. Ten Universal destinations plus a collapsible second Universal or location-specific bank are available. Right-click a destination to choose folder/keybind, clear it or make it click-only. Tab swaps MOVE/COPY. Moving advances; copying retains the current image and does not enter undo history. ONE-TIME chooses a destination for one operation. Named sets and other folder sets can be copied individually or as a whole. Conflicts preview incoming/existing files and offer overwrite, rename or cancel. Rename suffixes increment in hexadecimal (_01, _0A, _10, _0100). Missing destinations offer another folder, creation or cancellation. Batch transfers show progress and cancellation; completed operations remain completed and undoable.

Clipboard, saving and recovery

Ctrl+C and Shift+C offer the same copy support: image clipboard formats for stills and file transfer for animations/videos or multi-selection. Ctrl+V imports a clipboard PNG into the current folder; on an empty startup it uses temp beside the executable, clearing oldest temporary images when over 50 MB. Incoming file drops offer View in original folder or Move to current folder. Ctrl+S opens Save Copy: JPG/PNG for stills, original-format copying for motion. Set destination, then Save copy at set location, or overwrite with a recoverable backup. Format conversion keeps the original. B sends files to the Windows Recycle Bin; confirmation is on by default. Ctrl+Z reverses up to five session operations, including batches, moves, trash and edits. Undo history is not retained after restarting.

Overlays, film strip and bookmarks

The context-menu Overlays submenu controls Zoom, Image Position, Slideshow, Diagnostics, Navigation Arrows, Film Strip, Metadata and Histogram. Right-click an entry or overlay for its options; close actions are provided. G toggles the film strip: drag or wheel through cached rounded thumbnails; the current image is larger with a red outline. Choose whether it covers or reduces the viewer. Folder Timeline gives visual folder progress and sits above the strip; EOF behaviour is shared with settings. Click Image Position to jump to a number. Bookmark Position saves the current filename; right-click lists up to five global bookmarks, newest first. Missing files are dimmed and struck through; remove unwanted entries. Bookmark data is loaded only when needed.

Slideshows

Y shows the timer, then starts/stops playback on subsequent use. Right-click the timer for Start/Stop, Set Time, Auto-hide, or End slideshow and close overlay. Left-click edits time: 0–999 minutes and 0–59.9 seconds; empty fields mean zero. Space pauses/resumes the slideshow, including over GIFs. Animations follow the interval; videos advance when finished. Still-image effects can randomly choose among enabled backgrounds, transitions and pan/zoom directions. Transitions are half a second. Motion files use ordinary playback. Opening effect options pauses the effect preview; quick sort preserves pan continuity. Closing the slideshow overlay ends playback. The timeline is visual feedback, not a seek bar.

Video and animation controls

The one-line video toolbar has play/pause, seek, volume, mute, previous/next frame (< and >) and Loop. Click the seek track to jump; drag to scrub. Frame stepping works while paused. Loop opens A/B controls; setting a loop ends an active slideshow and changing files clears it. Wheel changes video volume, Ctrl-wheel zooms, and Shift-wheel navigates only when the wheel-navigation option is enabled. GIF/WebP use ordinary zoom. Volume starts at 25% on each launch. Mute sets the slider to zero and unmute restores the prior volume. Videos without audio dim volume controls and do not change the saved volume on wheel use. Optional pause-on-focus-loss is off on fresh settings; gazegallery menus do not trigger it.

Edit mode and cropping

C enters Edit mode on a still image. Draw/resize a crop, Space-drag to pan, or zoom. C/Escape cancels without saving. Apply and save replaces the original with a recoverable backup; Save as copy uses an incrementing _cropped suffix and stays in Edit mode. Flips/rotations can be saved without a crop. Aspect presets include square, 9:16, 16:9, 4:3 and custom; choosing one creates a centred crop and enables lock. Shift-drag a corner disables lock until enabled again. Allow overcropping fills outside bounds with the canvas colour; it is off on fresh settings. The rotation ruler previews angle with a grid, with reset and clockwise-90° controls.

Image adjustments

Adjustments preview in real time without saving until applied. Groups include brightness, exposure, gamma, contrast, highlights, shadows, white/black points, hue, saturation, warmth, tint, sepia, posterize, sharpness and vignette. Composite controls adjust/invert red, green and blue independently. Greyscale and invert are explicit editing effects. Threshold must be enabled before adjusting the black/white midpoint. Blur supports Gaussian, box and motion; draw a direction/length line for whole-image motion blur. Individual resets and Reset All are available. Rotating retains the original dimensions and crops corners. The ordinary I greyscale viewing filter remains separate from saved adjustments.

Collage canvas

Start collage uses the viewed image or selected thumbnails; no thumbnail selection disables it. Imported images start deselected and fit within 60% of the window. Drag/drop and paste add centred images without automatically packing. Click to select/front, Ctrl/Shift-click for multiple, drag a group to move, or a corner to resize only that image. Respect Aspect Ratio is on by default; Shift preserves ratio temporarily. Left-click empty space deselects; right-click outside preserves selection. Double-click an image fits the canvas view and enters wrapped import-order navigation; double-click background toggles fullscreen. Enter also toggles fullscreen. Open another viewer opens the starting image.

Collage tools and export

O/Ctrl+A/Select All toggles selection. L equalizes area; P packs tightly to the viewport and deselects. Normalize Width/Height uses the largest selected dimension. Align Row/Column follows import order and reverses on repeated use, using midpoints where sizes differ. Gap Size is 0–1000 px and applies on the next Pack/Align. Reset Size restores natural size while keeping centre/crop; Reset Aspect restores source ratio. C crops one collage image locally, clamped to source bounds; B removes selected/focused images and Clear is undoable. Moving pictures are excluded. The initial 50-image limit can be increased in 50-image steps up to 200. Export previews arrangement and highest-quality dimensions, supports JPG (95% default) or PNG, and linked width/height with a 3000-px default longest edge. Export is flattened; leaving unloads the canvas after confirmation.

Metadata and histogram

Metadata shows full filename, modification time, dimensions, file size, DPI, bit depth and descriptive fields. Rename the filename or edit supported title/subject/rating/tags/comments and Save. JPEG metadata uses supported EXIF fields; other formats may use .gazegallery-metadata.json sidecars. Expand to inspect EXIF. Unique-colour count and JPEG quality estimate require explicit analysis so they do not slow loading. Histogram displays selectable red, green, blue and grey channels from the original image. Metadata and Histogram entries are hidden on fresh context-menu settings until enabled.

Bundled plugins

Simple Draw (U): brush, eraser, previewed line tool, editable size (8 default) with a half-to-double slider, two colour swatches, Alt-click colour pick, five-stroke Ctrl+Z, Clear All, pointer-size circle, wheel zoom and Space-drag pan. Apply saves a copy. Wallpaper: choose desktop wallpaper or lock screen, preview monitor aspect/fit, drag framing and wheel zoom. Color Picker (Shift+P): one pixel or averaged circle, adjustable radius, three recent swatches and pixel position/RGB/hex/HSL/HSV/CMYK readouts. Plugins run with the same access as the application; install only trusted plugins. See PluginGuide.md for the C# API.

Settings and data

General settings use collapsible groups. Configure startup, background/OLED/checkerboard, fit, cursor hiding, confirmations, performance, navigation and transitions. Colours include per-colour Random and Random All. Bindings supports search, typed or captured inputs, and a keyboard/mouse guide. Context Menu controls order, separators and which entries appear, including Overlays entries. Title Bar controls ordered fields; dimensions remain linked and collage has separate options. Export Settings includes saved destinations, presets, external programs, palettes and preferences; Import restores exported data. Portable user data stays beside the executable and is not included in release ZIPs. Back up important files before editing or batch operations.

Troubleshooting and credits

Extract the whole archive rather than running the executable inside it. Use a writable folder and keep bundled runtime/plugins together. A new portable extraction starts with fresh settings; import a settings export to retain preferences. Include version, file format, reproduction steps and diagnostics when reporting an issue; do not upload private images without checking them. This build has code-level checks, not a promise of testing on every machine. Windows Recycle Bin integration could not be verified in the restricted development shell and should be tested with disposable files. Coder: Codex.
