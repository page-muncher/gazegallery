gazegallery 0.37.0
==================

A portable, fast image viewer, folder browser and reference collage canvas for Windows x64.

QUICK START
Extract the entire ZIP to a writable folder. Double-click gazegallery.exe.
Drag an image onto the top half to view its original folder, or choose Open File.
Use X/Tab for Folder Tree, Z for thumbnails, and right-click for actions.
Keep runtime, plugins and Support beside the executable.

USEFUL DEFAULT KEYS
F / D / Right / mouse forward: next
A / S / Left / mouse back: previous
Q: quick sort; Tab inside quick sort: copy/move
B: recycle; Ctrl+Z: undo (five session operations)
Ctrl+C / Shift+C: copy; Ctrl+V: paste; Ctrl+S: save copy/export
C: Edit mode (collage: local crop); Enter: fullscreen
H / N / R: horizontal flip / vertical flip / clockwise rotation (view only)
I: greyscale view; G: film strip; Y: slideshow overlay/start-stop
Space: slideshow/media pause, or thumbnail autoscroll
U: Simple Draw; Shift+P: Color Picker; F12: diagnostics
Collage: O/Ctrl+A select all, L equal area, P pack, B remove

Full_Guide.html is the complete offline guide. It covers layouts, filters, previews,
video A/B looping, overlays/bookmarks, image adjustments, collage export and plugins.
Settings provides export/import, startup choices, bindings and Windows associations.
